# 🎭 说话人角色设置功能

## 📋 功能概述

在语音转文本的"对话内容"区域，增加了**角色设置**功能，可以将转录中的所有说话人（SPEAKER_1, SPEAKER_2等）标记为"客户"或"我方"，便于后续分析和整理。

---

## ✨ 功能特性

### 1. **角色分配**
- 支持将说话人标记为：
  - 👤 **客户**：蓝色标签
  - 👔 **我方**：绿色标签
  - **未设置**：无标签

### 2. **可视化显示**
- 对话列表中，每个说话人后面显示对应的角色标签
- 客户标签：蓝色背景 `#e6f7ff`
- 我方标签：绿色背景 `#f6ffed`

### 3. **持久化存储**
- 角色设置保存在 `transcriptions.speaker_roles` 字段（JSON格式）
- 重新加载转录时自动恢复角色设置

---

## 🎯 使用步骤

### 步骤 1：打开角色设置
1. 在"语音转文本"页面，加载已转录的内容（或完成新转录）
2. 在"对话内容"区域，点击 **"👥 角色设置"** 按钮
3. 展开角色设置面板

### 步骤 2：分配角色
1. 系统自动识别所有唯一的说话人（如 SPEAKER_1, SPEAKER_2）
2. 为每个说话人选择角色：
   - 点击"👤 客户"，标记为客户方
   - 点击"👔 我方"，标记为己方
   - 点击"未设置"，取消角色标记

### 步骤 3：保存设置
1. 点击 **"💾 保存角色设置"** 按钮
2. 系统提示"角色设置已保存！"
3. 角色设置面板自动收起
4. 对话列表刷新，显示角色标签

### 步骤 4：查看效果
- 在对话列表中，每条对话的说话人后面显示对应角色标签
- 例如：
  ```
  00:01-00:03 SPEAKER_1 👤 客户 ：您好，我想了解一下产品...
  00:05-00:08 SPEAKER_2 👔 我方 ：您好！很高兴为您介绍...
  ```

## 🔧 技术实现

### 数据库字段
```sql
-- transcriptions 表新增字段
speaker_roles TEXT NULL COMMENT '说话人角色设置（JSON格式）'
```

### 数据格式
```json
{
  "SPEAKER_1": "customer",
  "SPEAKER_2": "our_side",
  "SPEAKER_3": "customer"
}
```

### 后端 API
**更新转录记录**
```
PUT /api/transcription/:id
Content-Type: application/json

{
  "speaker_roles": "{\"SPEAKER_1\":\"customer\",\"SPEAKER_2\":\"our_side\"}"
}
```

### 前端状态管理
```javascript
// 全局状态
let st_speakerRoles = {}; 

// 加载角色设置
if (data.speaker_roles) {
  st_speakerRoles = JSON.parse(data.speaker_roles);
}

// 渲染角色标签
const role = st_speakerRoles[speaker];
if (role === 'customer') {
  roleTag = '<span class="role-badge role-customer">👤 客户</span>';
} else if (role === 'our_side') {
  roleTag = '<span class="role-badge role-our-side">👔 我方</span>';
}
```

## ⚠️ 注意事项

1. **角色设置是可选的**
   - 未设置角色不影响基本功能
   - 可随时添加或修改角色设置

2. **角色与说话人名称独立**
   - 修改说话人名称（如 SPEAKER_1 → 张三）后，角色设置仍然生效
   - 角色设置基于原始说话人标识

3. **批量替换说话人后**
   - 如果将 SPEAKER_1 批量替换为"张三"
   - 原 SPEAKER_1 的角色设置会丢失
   - 建议先设置角色，再批量替换名称
