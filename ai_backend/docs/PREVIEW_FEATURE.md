# 在线预览功能说明

## ✨ 新增功能

提取完成后，可以直接在浏览器中查看提取的内容，无需下载文件。

---

## 🎯 功能特点

### 1. 在线预览

- ✅ **查看详细版**：查看每个文本片段的详细信息
- ✅ **查看拼接版**：查看按幻灯片合并后的完整文本
- ✅ **表格渲染**：自动将制表符分隔的内容渲染为美观的表格
- ✅ **大文件支持**：支持查看超大文件（数千行数据）

### 2. 内容操作

- ✅ **复制内容**：一键复制全部内容到剪贴板
- ✅ **下载文件**：直接从预览界面下载文件
- ✅ **行数统计**：自动统计数据行数

### 3. 界面体验

- ✅ **模态框显示**：不离开当前页面
- ✅ **平滑动画**：优雅的打开/关闭动画
- ✅ **响应式设计**：适配各种屏幕尺寸
- ✅ **高性能渲染**：即使数据量大也流畅显示

├───────────────────────────────────────────────────────┤

│ │ 文件名 │ 主ID │ 子ID │ 文本内容              │ │
│ ├─────────────────────────────────────────────────┤ │
│ │ 一表通 │ s1   │ e1   │ 产品概述              │ │
│ │ 一表通 │ s1   │ e2   │ 核心功能              │ │
│ │ 一表通 │ s2   │ e1   │ 应用场景              │ │
│ │ ...                                           │ │
│ └─────────────────────────────────────────────────┘ │
│                                                       │
└───────────────────────────────────────────────────────┘

### 操作按钮

#### 复制内容
- 点击"复制内容"按钮
- 全部内容会被复制到剪贴板
- 可以直接粘贴到其他应用

#### 下载文件
- 点击"下载文件"按钮
- 浏览器会下载该文件

#### 关闭预览
- 点击右上角 [×] 按钮
- 或点击模态框外部区域
- 或按 ESC 键（待实现）

## 🎨 界面特性

### 表格渲染

**详细版文件**（制表符分隔）会自动渲染为表格：

**原始文本**：
```
文件名	主ID	子ID	文本内容
一表通	slide_1	element_1	产品概述
```

**渲染效果**：

| 文件名 | 主ID | 子ID | 文本内容 |
|-------|------|------|---------|
| 一表通 | slide_1 | element_1 | 产品概述 |

### 纯文本渲染

**拼接版文件**会显示为纯文本，保持原格式：

```
文件名	主ID	拼接文本内容
====================================
一表通	slide_1	产品概述 核心功能 适用场景
一表通	slide_2	应用场景 技术优势
```

## 🔧 技术实现

### 后端 API

**接口**: `GET /api/preview?file=/output/2026-01-03/xxx.txt`

**功能**:
- 读取指定文件内容
- 安全检查（只能访问 output 目录）
- 返回文件内容

**响应**:
```json
{
  "success": true,
  "content": "文件内容...",
  "file": "document_1_2026-01-03T10-30-00.txt"
}
```

### 前端实现

#### 1. 模态框组件
- HTML 结构：`.modal` > `.modal-content`
- CSS 动画：淡入 + 上滑效果
- 点击外部关闭

#### 2. 内容渲染
```javascript
// 检测是否是表格格式
if (content.includes('\t')) {
    // 渲染为 HTML 表格
    renderTable(content)
} else {
    // 渲染为纯文本
    renderText(content)
}
```

#### 3. 操作功能
- 复制：使用 `navigator.clipboard.writeText()`
- 下载：直接访问文件 URL

## 🐛 故障排查

### 问题 1: 预览无法打开

**原因**：文件路径错误或文件不存在

**解决**：
1. 检查文件是否在 `output/` 目录
2. 刷新页面重试
3. 查看浏览器控制台错误

### 问题 2: 内容显示乱码

**原因**：文件编码不是 UTF-8

**解决**：
1. 确保提取器使用 UTF-8 保存文件
2. 检查源 JSON 文件编码

### 问题 3: 表格显示不正常

**原因**：文件不是制表符分隔格式

**解决**：
1. 这可能是拼接版文件（纯文本格式）
2. 详细版才会显示为表格
