## 🚀 快速使用

### 步骤 1：创建第一个提示词模板

1. 打开 http://localhost:3000/analysis.html
2. 确保在 **"📝 提示词管理"** 标签页
3. 点击右上角的 **"➕ 新建提示词"** 按钮
4. 填写表单：

   **必填项**：
   - **模板名称**：例如 "PPT内容深度分析"
   - **代码标识**：例如 "ppt_deep_analysis"（创建后不可修改）
   - **提示词内容**：编写您的AI提示词

   **选填项**：
   - **类型**：选择 "PPT分析"
   - **描述说明**：简要说明这个提示词的用途
   - **排序**：数字越小越靠前（默认0）
   - **激活状态**：勾选表示立即激活

5. 点击 **"保存"**

### 步骤 2：使用自定义提示词进行测试

1. 切换到 **"🧪 分析测试"** 标签页
2. 在 **"选择提示词模板"** 下拉框中选择您创建的模板
3. 输入测试文本
4. 点击 **"🔍 开始分析"**
5. 查看AI使用您的自定义提示词返回的分析结果

## 📝 提示词编写技巧

### 使用占位符

在提示词内容中，您可以使用 `{categories}` 占位符，系统会自动替换为完整的分类标准列表。

**示例**：

```
你是一位专业的PPT内容分析专家。

## 分类标准

{categories}

## 分析要求

1. 仔细阅读文本内容
2. 对比分类标准
3. 选择最佳分类（必须选择二级分类code）

## 输出格式

```json
{
  "category_code": "二级分类code",
  "confidence": 0.95,
  "reason": "分类理由"
}
```
```

### 提示词模板结构建议

1. **角色定义**：明确AI的角色（如：PPT内容分析专家）
2. **任务说明**：清楚说明要做什么
3. **分类标准**：插入 `{categories}` 占位符
4. **分析步骤**：列出具体的分析步骤
5. **输出格式**：明确要求JSON格式输出
6. **注意事项**：特别强调的要点
7. **示例**：提供一个示例（可选）

## 🔧 功能说明

### 提示词状态管理

- **激活**（✅）：可以在分析测试中使用
- **停用**（⏸️）：不会出现在选择列表中，但保留在系统中

**快速切换**：点击提示词卡片上的 ⏸️ 或 ▶️ 按钮

### 查看提示词详情

点击 **"👁️ 查看"** 按钮可展开查看完整的提示词内容，再次点击 **"收起"** 隐藏。

### 编辑提示词

1. 点击 **"✏️ 编辑"** 按钮
2. 修改需要的字段
3. 点击 **"保存"**

**注意**：代码标识（code）创建后不可修改，以确保系统稳定性。

### 删除提示词

点击 **"🗑️"** 按钮，确认后删除。

⚠️ **警告**：删除操作不可恢复，请谨慎操作！

## 🔍 API 接口说明

如果您需要通过API直接调用：

### 获取提示词列表
```bash
GET /api/ppt-analysis/prompts
```

### 创建提示词
```bash
POST /api/ppt-analysis/prompts
Content-Type: application/json

{
  "name": "提示词名称",
  "code": "prompt_code",
  "type": "ppt_analysis",
  "description": "描述",
  "prompt": "提示词内容",
  "isActive": true,
  "sortOrder": 0
}
```

### 更新提示词
```bash
PUT /api/ppt-analysis/prompts/:id
```

### 删除提示词
```bash
DELETE /api/ppt-analysis/prompts/:id
```

### 激活/停用
```bash
PATCH /api/ppt-analysis/prompts/:id/toggle
```

### 使用自定义提示词分析
```bash
POST /api/ppt-analysis/analyze-single
Content-Type: application/json

{
  "slideText": "要分析的文本",
  "promptId": "提示词ID",
  "modelName": "custom-openai"
}
```

## ❓ 常见问题

### Q1: 为什么我看不到提示词管理标签？

**A**: 请确保您已经刷新了浏览器页面。按 `Ctrl + F5`（Windows）或 `Cmd + Shift + R`（Mac）强制刷新。

### Q2: 创建提示词时代码标识应该怎么填？

**A**: 使用小写字母、数字和下划线，例如：`ppt_content_v1`、`financial_analysis`。代码标识需要唯一，创建后不可修改。

### Q3: {categories} 占位符会被替换成什么？

**A**: 系统会自动替换为数据库中所有激活的分类标准的完整列表，包括名称、代码和描述。

### Q4: 如果不选择提示词模板，会使用什么提示词？

**A**: 系统会使用默认的提示词（在 `ai_backend/server/prompts/pptAnalysisPrompt.js` 中定义）。

### Q5: 可以同时激活多个提示词吗？

**A**: 可以。您可以激活多个提示词模板，在测试时选择需要使用的那个。

### Q6: 提示词是否支持Markdown格式？

**A**: 提示词内容会原样发送给AI，AI通常能理解Markdown格式，但具体效果取决于AI模型。

## 📊 数据库表结构

提示词数据存储在 `prompt_templates` 表中：

```sql
CREATE TABLE prompt_templates (
  id VARCHAR(50) PRIMARY KEY,
  name VARCHAR(100) NOT NULL,
  code VARCHAR(100) UNIQUE NOT NULL,
  type VARCHAR(50) NOT NULL,
  description TEXT,
  prompt TEXT NOT NULL,
  is_active BOOLEAN DEFAULT true,
  sort_order INT DEFAULT 0,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);
```
