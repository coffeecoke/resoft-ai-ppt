# 自动跑批监控系统

## 📋 功能概述

自动跑批监控系统是一个智能的PPT文档处理自动化工具,可以:

1. **自动扫描**: 定时扫描未提取的PPT文档
2. **智能检测**: 检查JSON文件是否存在,避免重复处理
3. **自动提取**: 发现新文件自动提取文本内容
4. **自动分类**: 提取完成后自动调用AI进行内容分类
5. **实时监控**: 实时显示处理进度和状态
6. **灵活配置**: 可自定义轮询间隔、功能开关等

## 🚀 快速开始

### 1. 访问页面

打开浏览器访问: `http://localhost:3000/admin.html`

在左侧菜单点击 **"🤖 自动跑批监控"**

### 2. 配置参数

在"⚙️ 配置设置"区域:

- **轮询间隔**: 设置自动扫描的时间间隔 (1分钟 ~ 1小时)
- **自动提取文本**: 是否自动提取未提取的文档
- **自动AI分类**: 是否自动对提取后的文档进行AI分类
- **最大并发数**: 同时处理的文档数量 (1-10)

点击 **"💾 保存配置"** 按钮保存设置。

### 3. 启动自动跑批

点击 **"▶️ 启动自动跑批"** 按钮,系统将:

1. 立即执行一次扫描和处理
2. 根据配置的轮询间隔定时执行
3. 在"📋 处理日志"区域显示处理过程

### 4. 监控运行状态

页面会实时显示:

- **运行状态**: 运行中/已停止
- **当前任务**: 正在处理的文档信息
- **统计数据**: 
  - 总文档数
  - 已提取文档
  - 已分析文档
  - 待处理文档
  - 执行次数统计
- **处理日志**: 详细的处理过程记录

## 🎮 控制操作

### 启动/停止

- **启动自动跑批**: 开始定时自动处理
- **停止自动跑批**: 停止定时任务(当前任务会完成)
- **立即执行一次**: 手动触发一次完整处理流程
- **刷新状态**: 手动刷新页面数据

### 日志管理

- 日志列表会自动刷新(每5秒)
- 点击 **"🗑️ 清空日志"** 可清除所有历史日志
- 日志保留最近100条记录

## 📊 统计指标说明

| 指标 | 说明 |
|------|------|
| 总文档数 | 系统中的所有PPT文档数量 |
| 已提取文档 | 完成文本提取的文档数量 |
| 已分析文档 | 完成AI分类的文档数量 |
| 待处理文档 | 未提取且JSON文件存在的文档数量 |
| 总执行次数 | 自动跑批任务的总执行次数 |
| 成功次数 | 成功完成的任务次数 |
| 失败次数 | 执行失败的任务次数 |
| 下次执行 | 距离下次自动执行的倒计时 |

## 🔄 处理流程

```
1. 扫描文档表
   ↓
2. 筛选未提取的文档
   ↓
3. 检查JSON文件是否存在
   ↓
4. 自动提取文本 (如启用)
   ↓
5. 自动AI分类 (如启用)
   ↓
6. 更新文档状态
   ↓
7. 记录处理日志
```

## 🐛 常见问题

### Q1: 为什么待处理文档数量为0?

**A**: 可能原因:
1. 所有文档都已提取
2. JSON文件不存在或路径不正确
3. 文档表中没有记录

**解决方法**: 
- 检查数据库`documents`表
- 确认JSON文件路径正确

### Q2: 自动跑批启动后没有处理?

**A**: 可能原因:
1. 待处理文档为0
2. 功能开关未开启
3. 后端服务异常

**解决方法**:
- 查看处理日志
- 检查配置设置
- 查看服务器日志

### Q3: JSON文件路径规则?

**A**: 系统会按以下顺序查找JSON文件:

1. 与PPT同目录: `文件名.json`
2. 提取目录: `online-ppt-backend/data/extracted/{documentId}/文件名.json`
3. 缩略图目录: `online-ppt-backend/data/thumbnails/{documentId}.json`

### Q4: 如何暂停当前任务?

**A**: 点击"停止自动跑批"按钮,当前任务会完成后停止。

### Q5: 日志可以导出吗?

**A**: 当前版本暂不支持导出,可以通过API接口获取:
```bash
GET /api/auto-process/logs?limit=100
```

## 💡 技术架构

### 后端服务

- **Service层**: `ai_backend/server/services/autoProcessService.js`
- **路由层**: `ai_backend/server/routes/autoProcessRoutes.js`
- **集成点**: `ai_backend/server/app.js`

### 前端页面

- **HTML**: `ai_backend/frontend/pages/auto-process.html`
- **JavaScript**: `ai_backend/frontend/js/pages/auto-process.js`

### 核心依赖

- **文档提取**: 调用`documentService`
- **AI分析**: 调用`pptAnalysisService`
- **数据库**: Prisma ORM
- **定时任务**: Node.js `setInterval`

## 📝 注意事项

1. **资源占用**: AI分析会消耗较多资源,建议合理设置并发数
2. **API配额**: 注意AI服务的调用次数限制
3. **数据备份**: 重要文档建议先备份再处理
4. **日志清理**: 定期清理日志以释放内存
5. **错误处理**: 及时查看日志,处理异常情况
