# PPT AI 分析管理页面 - 使用指南

## 🎯 访问地址

启动 ai_backend 服务后，在浏览器访问：

```
http://localhost:3000/analysis.html
```

## 📋 功能模块

### 1. 🧪 **分析测试** (单页测试)

**用途**: 快速测试AI分析功能

**操作步骤**:
1. 在文本框中输入PPT页面内容
2. 选择AI模型（推荐使用 Custom OpenAI）
3. 点击"开始分析"
4. 查看分析结果：
   - 分类代码
   - 分类名称
   - 置信度（百分比）
   - 分类理由
   - 判断标准

**测试示例**:
```
XX科技公司成立于2010年，是一家专注于金融监管科技的高新技术企业。
公司总部位于北京，在上海、深圳设有分支机构。
公司拥有员工200余人，其中研发人员占比60%，年营收达2亿元。
```

预期分类：`enterprise_basic_info` (企业基础信息)

---

### 2. 📚 **批量分析** (文档分析)

**用途**: 对整个PPT文档进行批量分析

**操作步骤**:
1. 点击"刷新文档列表"加载文档
2. 从下拉框选择要分析的文档
3. 查看文档信息（页数、已提取文本数）
4. 选择AI模型
5. 点击"开始分析"
6. 实时查看进度条和当前处理页面
7. 分析完成后查看统计结果

**注意事项**:
- ⚠️ 文档必须先提取文本（在"文档管理"页面操作）
- ⏱️ 大文档分析需要较长时间
- 📊 分析过程中会实时更新进度

**操作按钮**:
- **开始分析**: 启动批量分析
- **查看结果**: 跳转到结果页面
- **查看统计**: 跳转到统计页面

---

### 3. 📊 **分析结果** (结果查看)

**用途**: 查看文档的详细分析结果

**显示内容**:
- 页面索引
- 页面ID
- 分类名称
- 分类代码
- 置信度（可视化进度条）
- 分析时间

**操作**:
- 点击"刷新"按钮更新数据
- 可按列排序（点击表头）
- 支持滚动查看长列表

---

### 4. 📈 **统计报表** (数据分析)

**用途**: 查看文档分类的统计信息

**概览卡片**:
- 📄 总页数
- ✅ 已分析页数
- ⏳ 未分析页数
- 🎯 平均置信度

**分类分布**:
- 每个分类的页面数量
- 占比百分比
- 可视化条形图
- 平均置信度

**使用场景**:
- 了解PPT内容组成
- 评估分析质量
- 发现内容偏重

---

### 5. 🏷️ **分类标准** (参考文档)

**用途**: 查看AI使用的分类标准

**分类体系**:
- **6个一级分类**
  1. 企业信息
  2. 合作案例
  3. 监管政策与行业背景
  4. 产品解决方案
  5. 部署实施及售后保障
  6. 其他

- **23个二级分类**
  - 每个一级分类下有多个具体分类
  - 显示分类代码
  - 显示详细的判断标准

**操作**:
- 点击一级分类展开/收起
- 查看每个分类的描述和判断标准
- 点击"刷新"更新数据


## 🐛 常见问题

### Q1: 页面打不开？
**A**: 检查服务是否启动：
```bash
curl http://localhost:3000/api/health
```

### Q2: 分析失败？
**A**: 检查：
1. 文档是否已提取文本
2. OpenAI API配置是否正确
3. 网络是否正常
4. 查看浏览器控制台错误

### Q3: 没有文档可选？
**A**: 
1. 先在"文档管理"页面上传文档
2. 提取文本内容
3. 刷新文档列表

### Q4: 进度卡住不动？
**A**:
1. 检查浏览器控制台
2. 刷新页面重试
3. 检查服务器日志
