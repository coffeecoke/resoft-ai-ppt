本目录包含用于 PPT 内容智能分析的提示词模板。

## 📁 文件说明

### 1. `ppt_analysis_prompt_professional.txt` （推荐）

**专业版提示词** - 详细完整版本

**特点：**
- ✅ 结构化的四步分析方法论
- ✅ 详细的置信度评估指南
- ✅ 4个不同类型的分类示例
- ✅ 严格的输出格式要求
- ✅ 特殊情况处理说明

**适用场景：**
- 需要高精度分类

- 描述：`专业的PPT内容分析提示词，采用四步分析法，包含详细示例和置信度指南`

## 🚀 使用方法

### 方式一：通过前端界面创建（推荐）

1. 访问 `http://localhost:3000/analysis.html`
2. 进入 **"📝 提示词管理"** 标签页
3. 点击 **"➕ 新建提示词"** 按钮
4. 填写表单：
   - 模板名称、代码标识、类型等
   - 从对应的 `.txt` 文件中**复制完整内容**
   - 粘贴到 **"提示词内容"** 大文本框
5. 勾选 **"激活状态"**
6. 点击 **"保存"**

### 方式二：通过API创建

```bash
curl -X POST http://localhost:3000/api/ppt-analysis/prompts \
  -H "Content-Type: application/json" \
  -d '{
    "name": "PPT内容智能分析（专业版）",
    "code": "ppt_content_analysis_pro",
    "type": "ppt_analysis",
    "description": "专业的PPT内容分析提示词",
    "prompt": "这里粘贴 ppt_analysis_prompt_professional.txt 的内容",
    "isActive": true,
    "sortOrder": 0
  }'
```

## ⚙️ 提示词变量说明

### `{categories}` 占位符

系统会自动将 `{categories}` 替换为数据库中所有激活的分类标准。

**替换示例：**

```
{categories}
```

**会被替换为：**

```
## 1. 企业基础信息 (enterprise_basic)
企业成立时间、规模、定位等基础信息

### 企业基础信息 (enterprise_basic_info)
包含企业名称、成立时间、注册资本、经营范围、企业规模、发展历程等

## 2. 产品介绍 (product_intro)
产品功能、特点、优势等介绍

### 产品功能介绍 (product_feature)
详细描述产品的核心功能、技术特点、应用场景等

...（更多分类）
```

**注意：** 
- ⚠️ 不要删除 `{categories}` 占位符
- ⚠️ 系统会从 `content_categories_ppt` 表读取分类
- ⚠️ 只有 `is_active = true` 的分类会被包含

## 🎯 提示词优化建议

### 1. 提高准确度
- 增加更多示例，覆盖各种分类场景
- 强调"必须选择二级分类"
- 明确特殊情况的处理方式

### 2. 提高稳定性
- 多次强调"只输出JSON"
- 提供清晰的JSON格式模板
- 说明置信度的评估标准

### 3. 适配特定场景
- 如果是金融行业，可以在示例中多用金融案例
- 如果是科技行业，可以强调技术特征的识别
- 根据实际分类标准调整示例

### 4. 降低成本
- 使用简化版提示词
- 减少示例数量
- 精简描述文字

## 🔧 常见问题

### Q1: 如何修改已创建的提示词？
A: 在前端界面点击提示词卡片的"✏️ 编辑"按钮，修改后保存即可。

### Q2: 可以创建多个提示词吗？
A: 可以！您可以创建多个不同版本的提示词，在测试时选择使用哪一个。

### Q3: 提示词支持中文吗？
A: 完全支持！提供的模板就是中文版本，AI能很好地理解中文指令。

### Q4: {categories} 占位符可以手动替换吗？
A: 不建议。系统会自动替换为最新的分类数据，手动替换会导致数据不同步。

### Q5: 如何测试提示词效果？
A: 切换到"🧪 分析测试"标签，选择提示词，输入测试文本，查看分析结果。
