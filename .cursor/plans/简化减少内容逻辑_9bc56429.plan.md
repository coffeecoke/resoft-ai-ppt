# 简化"减少内容"功能

## 修改目标

**当前问题**：

- 减少内容时使用AI智能选择保留哪些要点
- 增加了不必要的AI调用成本和延迟
- 可能删除用户认为重要的内容

**修改方案**：

- 添加配置开关，通过条件控制选择使用哪种模式
- 默认使用简单模式：直接删除最后一项（简单、可预期）
- 保留AI代码，可通过配置切换到AI智能选择模式
- 保留模板选择功能（用户仍可选择适配新数量的模板）

## 修改内容

### 文件：`online-ppt-backend/src/routes/aipptChat.js`

#### 1. 添加配置开关（第20-23行）

**新增代码**：

```javascript
// 配置：减少内容时是否使用AI智能选择
// true: 使用AI分析哪些要点重要，智能选择保留
// false: 直接删除最后一项（简单、快速、可预期）
const USE_AI_FOR_DECREASE = false
```

**原代码**：

**修改后代码**：

```javascript
if (isDecrease) {
  // 减少：默认减少1个，最少保留1个
  targetCount = Math.max(1, currentCount - 1)
  
  if (USE_AI_FOR_DECREASE) {
    // 【AI模式】使用AI智能选择保留哪些要点（更智能，但需要AI调用）
    // 保留原有AI代码逻辑...
    if (currentCount > 2) {
      try {
        const selectPrompt = `...`
        const result = await aiService.chat(model, [...])
        // ... AI选择逻辑
      } catch (e) {
        newItems = currentItems.slice(0, targetCount)
      }
    } else {
      newItems = currentItems.slice(0, targetCount)
    }
  } else {
    // 【简单模式】直接删除最后一项（默认模式）
    // 理由：1. 用户添加的顺序通常代表优先级，最后添加的往往是最不重要的
    //       2. 操作可预期，不会"智能"删除用户认为重要的内容
    //       3. 减少AI调用，提升响应速度
    newItems = currentItems.slice(0, targetCount)
    
    console.log(`[减少内容] 从${currentCount}项减少到${targetCount}项，删除最后${currentCount - targetCount}项（简单模式）`)
  }
}
```

**关键改进**：

- ✅ 保留所有AI代码，用条件包裹
- ✅ 添加配置开关，便于后续切换
- ✅ 默认使用简单模式，性能更好
- ✅ 如需AI模式，只需修改配置变量

## 数据流对比

### 修改前

```javascript
用户点击"减少内容"
  → 后端AI分析哪些要点重要
  → AI返回要保留的编号
  → 后端根据编号筛选items
  → 返回调整后的items
  → 前端显示ContentAdjust（选择模板）
```



### 修改后

```javascript
用户点击"减少内容"
  → 后端直接删除最后一项
  → 返回调整后的items（立即返回，无延迟）
  → 前端显示ContentAdjust（选择模板）
```



## 优势

1. **响应速度**：无AI调用，立即返回
2. **可预期性**：用户知道删除的是最后一项
3. **成本降低**：减少AI API调用
4. **稳定性**：无AI解析失败的风险
5. **保留功能**：模板选择功能完全保留

## 用户体验

**操作流程不变**：

1. 用户点击"减少内容"
2. 看到调整后的items（数量-1）
3. 可以选择适配新数量的模板样式
4. 确认后更新当前页面

**唯一变化**：

- 删除的是最后一项（而不是AI认为"不重要"的项）
- 响应更快（无AI延迟）
