# 修复"增加内容"功能

## 问题描述

用户使用"增加内容"功能时，发现两个问题：

### 问题1：内容顺序和风格被改变

原有内容可能被重新组织或修改。

### 问题2：新增内容风格不一致

**原有内容风格**：

```javascript
{title: "+82%", text: "数据填报效率提升"}
{title: "+85%", text: "审批流转效率提升"}
```



- title：数据指标（简短）
- text：说明文字（简短）

**新增内容风格**（错误）：

```javascript
{title: "数据查询效率提升", text: "用户通过系统快速查询、筛选及获取目标数据的效率显著提升，效率提升+87%"}
```



- title：说明文字
- text：长篇描述

## 根本原因

后端 [`aipptChat.js:376-406`](online-ppt-backend/src/routes/aipptChat.js) 的 AI prompt 不够精确：

```javascript
const addPrompt = `以下是PPT中现有的要点，请补充一个相关的新要点。

页面标题：${currentSlide?.data?.title || currentSlide?.title || '未知'}
现有要点：
${currentItems.map((item, i) => `${i + 1}. ${item.title || item}: ${item.text || ''}`).join('\n')}

请返回一个新要点，格式：{"title":"要点标题","text":"要点说明"}
只返回JSON，不要其他内容。`
```

**问题**：

1. 没有明确要求"保持原有内容不变"
2. 没有提供原有内容的风格示例
3. 没有强调"title 和 text 的格式必须与原有一致"

## 修复方案

### 修改文件：`online-ppt-backend/src/routes/aipptChat.js`

修改 `handleAdjustContent` 函数中的增加内容逻辑（第376-406行）**当前代码**：

```javascript

${currentItems.map((item, i) => `${i + 1}. ${item.title || item}: ${item.text || ''}`).join('\n')}

```

**修改后代码**：

```javascript
// 分析现有内容的风格特征
const titleLengths = currentItems.map(item => (item.title || '').length)
const textLengths = currentItems.map(item => (item.text || '').length)
const avgTitleLen = Math.round(titleLengths.reduce((a, b) => a + b, 0) / titleLengths.length)
const avgTextLen = Math.round(textLengths.reduce((a, b) => a + b, 0) / textLengths.length)

// 检测是否有特殊格式（如百分比、数字）
const hasPercentage = currentItems.some(item => 
  (item.title || '').includes('%') || (item.title || '').match(/[+\-]\d+/)
)

const addPrompt = `你是PPT内容生成专家。用户要在PPT页面中增加一个新的内容项。

【重要】新增内容必须严格遵循现有内容的格式和风格！

页面标题：${currentSlide?.data?.title || currentSlide?.title || '未知'}

现有内容（共${currentItems.length}项）：
${currentItems.map((item, i) => {
  const title = item.title || item
  const text = item.text || ''
  return `${i + 1}. title: "${title}" (${title.length}字)\n   text: "${text}" (${text.length}字)`
}).join('\n')}

【格式要求】：
1. title字段：约${avgTitleLen}字，${hasPercentage ? '包含数据指标（如百分比、数字）' : '简短精炼'}
2. text字段：约${avgTextLen}字，${textLengths[0] < 15 ? '简短说明' : '详细描述'}
3. 风格必须与上述${currentItems.length}项完全一致
4. 内容要与页面主题相关，但不要重复现有要点

请严格按照以下JSON格式返回，不要有其他内容：
{"title":"[${avgTitleLen}字左右]","text":"[${avgTextLen}字左右]"}

【示例参考】：基于第1项的格式
{"title":"${currentItems[0].title || '示例标题'}","text":"${currentItems[0].text || '示例说明'}"}`
```



## 修改步骤

### 1. 修改后端 prompt（核心修复）

文件：`online-ppt-backend/src/routes/aipptChat.js` 第376-406行**关键改进**：

- 计算现有内容的平均长度
- 检测是否有特殊格式（百分比、数字）
- 明确告诉AI要保持相同的格式
- 提供具体的字数要求
- 给出第一项作为格式示例

### 2. 返回数据增强

在返回结果前添加验证：

```javascript
// 第397行之后添加
const newItem = JSON.parse(jsonMatch[0])

// 【新增】验证新内容的格式是否与现有一致
const titleLen = (newItem.title || '').length
const textLen = (newItem.text || '').length

// 如果长度差异过大，进行调整
if (Math.abs(titleLen - avgTitleLen) > avgTitleLen * 0.5) {
  console.warn(`[增加内容] 新内容title长度(${titleLen})与平均值(${avgTitleLen})差异过大`)
}
if (Math.abs(textLen - avgTextLen) > avgTextLen * 0.5) {
  console.warn(`[增加内容] 新内容text长度(${textLen})与平均值(${avgTextLen})差异过大`)
}

newItems = [...currentItems, newItem]
```



### 3. 前端显示原有内容

为了让用户清楚看到原有内容被保留，可以在 `ContentAdjust.vue` 中区分显示：

  <!-- 新增内容 -->
